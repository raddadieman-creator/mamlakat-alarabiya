# مملكة العربية

رحلة في جمال لغتنا لطالبات الصف الرابع الابتدائي: جزر الخط، والإملاء، والقراءة، والخطابة، مع مكتبة قصصية، وأعلام العربية، وشارات الإنجاز، ولوحة للمعلمة تضم الفصول والطالبات ولوحة النتائج.

## الاستضافة
- الواجهة: Vercel (يُنشر تلقائيًّا عند كل تحديث لهذا المستودع)، وتعمل أيضًا على GitHub Pages.
- قاعدة البيانات وحسابات المعلمات: Supabase (مشروع mamlakat-alarabiya). كل معلمة ترى بيانات فصولها فقط، بقواعد أمان على مستوى الصفوف (RLS).

## لوحة المعلمة
- **الحساب:** تُنشئ المعلمة حسابًا بالبريد وكلمة المرور، فتُحفظ الفصول والطالبات والنقاط والنتائج في الحساب، وتظهر على أي جهاز تدخل منه.
- **الطالبات والفصول:** إنشاء الفصول، ورفع أسماء الطالبات من ملف Excel (xlsx أو csv) بعمودين: «اسم الطالبة» و«الفصل». القالب الجاهز: `قالب-أسماء-الطالبات.xlsx`.
- **إدخال الدرجات:** درجات القياس القبلي والبعدي لكل طالبة، أو جلسة القياس كاملة داخل المنصة.
- **لوحة النتائج:** نقاط الجزر وتوزيع المستويات ومقارنة الفصول، ونتائج القياس القبلي والبعدي مع حجم الأثر، مع تصفية حسب الفصل.
- **الرمز السري:** يقفل لوحة المعلمة على جهاز الفصل، ويبقى الجهاز مرتبطًا بالحساب فتُحفظ نقاط الطالبات.

## دون إنترنت
تبقى نسخة من البيانات على الجهاز، وتُرسل التغييرات إلى الحساب عند عودة الاتصال. التسجيلات الصوتية تبقى على الجهاز الذي سُجّلت فيه.
